# Scanner Page Override

The scanner is the primary classroom workflow. Use a dark operations-console surface with high contrast, visible 2px borders, square corners, and a lime action color. Keep the scan action above the fold and show uncertainty as an explicit amber state.

- Primary background: `#080c09`
- Panel background: `#111a14`
- Action accent: `#c7ff54`
- Caution accent: `#ffd166`
- Error accent: `#ff8a7c`
- Body text: `#f3f7ed`
- Minimum touch target: `44px`
- Focus ring: `3px solid #c7ff54`
- Typography: Cascadia Mono / Space Mono for headings and labels; Segoe UI for longer explanatory text
- Icons: Lucide React only; no emoji icons
- Motion: 150–300ms color transitions; respect `prefers-reduced-motion`

The page must remain usable on Windows Chrome and Microsoft Edge. Camera capture is a browser hint; the upload control is always available as the reliable fallback.
